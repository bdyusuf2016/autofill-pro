# Autofill Pro

This is an advanced autofill extension with profile-based hotkeys and URL rules.

## Language Switch

The language of the extension can be changed in the settings page. To change the language, please follow the steps below:

1. Open the extension's options page.
2. Go to the **Settings** tab.
3. Select your preferred language from the **Language** dropdown menu.

The page will automatically reload and the new language will be applied to the extension.

**Supported Languages**

* English
* Bengali

Enjoy the extension!
