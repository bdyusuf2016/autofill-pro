Profile Hotkey Configuration

Assign keyboard shortcuts to quickly fill specific profiles

📝 How to Set Hotkeys:

  • Click on a profile's "Set Hotkey" button
  • Press your desired key combination (e.g., Ctrl+Shift+1)
  • Hotkeys work globally across all tabs
  • They won't trigger when typing in input fields
  • Maximum 10 profile hotkeys recommended
⚠️ Note: Avoid using common browser shortcuts (Ctrl+T, Ctrl+W, etc.)
