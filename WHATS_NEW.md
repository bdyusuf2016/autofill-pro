## 🚀 Quick Start - Cloud Login

### New Users
1. Click **☁️ Login** banner in popup
2. Create account
3. Enable Cloud Sync in options
4. Done! Your profiles sync automatically

### Existing Users
1. Go to Options → **☁️ Cloud Sync**
2. Click **🔐 Login to Cloud**
3. Enter your credentials
4. Enable Cloud Sync
5. Your profiles will sync!

### Multi-Device Setup
1. Install on 2nd computer
2. Login with same account
3. Click "⬇️ Download from Cloud"
4. All profiles appear automatically!
